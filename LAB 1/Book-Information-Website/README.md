# Book Information Website

## About the Project

A web-based book information website that displays a collection of books. Users can browse the available books and click on a particular book to view its detailed information on a separate page. This project demonstrates the fundamentals of web development by creating a multi-page website with interactive features and a user-friendly interface.

## Features

- **Displays Multiple Books** - Browse through a curated collection of books on the homepage
- **Individual Book Pages** - Each book has its own dedicated page with detailed information
- **Book Images** - Visual representation of each book with cover images
- **Book Information** - Title, author, description, and other relevant details for each book
- **Category-Based Organization** - Books are organized by categories for easy navigation
- **Search Functionality** - Search for books by title or keyword
- **Category Filtering** - Filter books by their respective categories
- **Sorting Functionality** - Sort books by various criteria (title, author, date, etc.)
- **Interactive User Interface** - Smooth navigation and engaging user experience
- **Responsive Design** - Website adapts to different screen sizes and devices

## Technologies Used

- **HTML5** - Semantic markup for structuring web pages
- **CSS3** - Styling and responsive layout design
- **JavaScript** - Client-side functionality and interactivity

### File Descriptions

- **index.html** - The main entry point of the website. Displays a collection of all books with thumbnails and basic information. Includes navigation links to individual book detail pages.

- **book1.html - book9.html** - Individual HTML pages for each book containing detailed information such as complete description, author bio, publication date, ISBN, rating, and other relevant details.

- **style.css** - Contains all CSS styling rules for the website including layout, colors, fonts, responsive design rules, and visual effects applied across all pages.

- **script.js** - Implements JavaScript functionality for interactive features such as search bar functionality, category filtering, sorting options, and other client-side operations to enhance user experience.

- **images/** - Directory that stores all image assets used in the project, including book cover images, icons, and any other visual elements.

## How to Run

1. **Download/Clone the Project** - Obtain all project files and ensure they are in the same directory.

2. **Open in Web Browser** - Navigate to the project folder and open `index.html` in your preferred web browser (Chrome, Firefox, Safari, Edge, etc.) by:
   - Right-clicking on `index.html` and selecting "Open with" → your browser
   - Or dragging `index.html` into an open browser window
   - Or using your browser's File menu to open the file

3. **Browse the Website** - Use the homepage to view all available books and click on any book to view its detailed information page.

4. **Test Features** - Try the search, filtering, and sorting features to explore the website's interactive capabilities.

**Note:** No server or installation is required. The website runs entirely in your browser as static files.
