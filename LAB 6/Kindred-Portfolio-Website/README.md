# Kindred Portfolio Website

## Project Description

Kindred is a dark-themed personal portfolio website for a frontend developer. The site presents a clear introduction, an about section, core frontend capabilities, and a contact form for starting a project discussion.

## Objective

The objective of this project is to create a responsive and accessible portfolio website that communicates a developer's skills and design approach through a focused, easy-to-navigate interface.

## Features

- Responsive portfolio layout for desktop and mobile screens
- Fixed navigation with links to Home, About, What I Do, and Contact sections
- Mobile navigation menu
- Hero section with a clear personal introduction and call-to-action
- About section focused on people-first web design
- Interactive Plan, Design, and Build capability cards
- Scroll-based reveal animations
- Active navigation link updates while scrolling
- Cursor glow and subtle decorative animations
- Contact form with required-field and email validation
- Success and validation messages for the contact form
- Back-to-top button
- Dark visual theme with a background image and green accent color

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts: DM Sans and Space Grotesk
- Browser APIs including `IntersectionObserver`, `localStorage`, and smooth scrolling

## How to Run the Project

1. Open the `Kindred-Portfolio-Website` folder.
2. Open `index.html` in a modern web browser.

No server or package installation is required.

## Key Functionality

- `script.js` controls the mobile menu, active section navigation, reveal animations, feature-card selection, contact-form validation, cursor movement effect, current year, and back-to-top behavior.
- `style.css` defines the responsive layout, dark theme, background image overlay, typography, cards, animations, and interactive states.
- `background.jpg` is used as the visual background for the page.
